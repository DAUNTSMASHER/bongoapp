# Story cover images

Place cover images here. Name them `bongochoti_online_golpo_01.png`, `bongochoti_online_golpo_02.png`, etc.

- **Supported formats**: .png, .webp, .jpg, .jpeg
- **Assignment**: Run `npx tsx scripts/assignCoverImages.ts` to assign covers to published stories (one random image per story).
- **New stories**: When crawling with `assignCoverImages: true`, new stories get a random cover from this folder.
- **Update images**: Add or replace images anytime – they are picked up automatically on the next assign or crawl.
